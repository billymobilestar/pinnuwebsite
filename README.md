# Pinnu Sekhon - Website

## Structure
```
/index.html              ← Portfolio site (pinnusekhon.com)
/valentines/index.html   ← Valentine's Day challenge (pinnusekhon.com/valentines)
```

## URLs
- `pinnusekhon.com` → Portfolio (permanent)
- `pinnusekhon.com/valentines` → Valentine's challenge (temporary)

## After Valentine's Day
Just delete the `/valentines` folder. The portfolio stays untouched.

## Deploy
Upload all files to GitHub, enable GitHub Pages or deploy to Vercel/Netlify.
